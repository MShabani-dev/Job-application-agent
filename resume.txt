**1. Full-Stack Architecture**
- Separation of backend (Django) and frontend (React) into independent applications
- Communication via RESTful API
- Running two services on separate ports (Django on 8000, Vite on 5173)
- Configuring CORS and baseURL

**2. Backend (Django & Django REST Framework)**
- **Models:** Topic and Entry models, ForeignKey relationships, related_name, owner and date_added fields, default User model, Profile, Like, and Vote models
- **Migrations:** makemigrations and migrate; resolving an author_id NOT NULL issue on legacy data
- **Serializers:** ModelSerializer, write_only password fields, create_user for password hashing, user profile serializer, computed fields such as score and entry_count
- **Views:** CreateAPIView, APIView, ModelViewSet, perform_create for setting the owner, custom @action endpoints (vote and hot)
- **ORM and Querying:** filtering, search, ordering, annotate and Count
- **Permissions:** AllowAny, IsAuthenticated, IsAuthenticatedOrReadOnly, custom IsOwnerOrReadOnly class, global vs. view-level permissions
- **URLs:** path, include, DefaultRouter, authentication endpoints (register, login, token refresh)
- **Django Admin:** registering models in admin.py, creating superusers, difference between session authentication (Admin) and JWT (API)

**3. Authentication**
- JWT authentication with SimpleJWT (access and refresh tokens)
- Configuring ACCESS_TOKEN_LIFETIME and REFRESH_TOKEN_LIFETIME
- Storing tokens in localStorage and sending them in request headers
- Auto-login after registration
- Logout by clearing tokens
- Handling token expiry and 401 errors

**4. Frontend (React)**
- **Core concepts:** components and props, useState and useEffect, Context API (ThemeContext), conditional rendering, controlled inputs and forms, lists and keys
- **Routing:** react-router-dom with BrowserRouter, Routes, Route, Link, and useNavigate; URL parameters (e.g., /topics/:id); 404 page; protected routes
- **API integration:** axios, a centralized axios instance in api.js, interceptors for attaching tokens and automatic token refresh, loading and error state management, fetch vs. axios
- **Pages and components:** Home, Topics, TopicDetail, Login, Register, Profile, Navbar, App, EntryCard, EmptyState, AnimatedBackground

**5. UI/UX and Styling**
- Tailwind CSS: utility classes, custom colors and fonts in tailwind.config.js, custom animations (e.g., animate-blob)
- Framer Motion: motion.div, initial/animate/transition, whileHover and whileTap
- lucide-react for icons
- Visual effects: glassmorphism (backdrop-blur), gradients, background video, gradient text, dark/light mode
- User experience: toast notifications, loading states, empty states
- Optimistic UI for voting and submitting entries
- Responsive, mobile-friendly design

**6. Features Built**

- Voting system (upvote and downvote)
